StakeScreener — modifications to HEX Stake Analyzer
===================================================

StakeScreener (https://stakescreener.com) is based on HEX Stake Analyzer
© 2026 HexStakeAnalyzer, licensed under GPL-3.0 (see LICENSE).
Original source: https://github.com/hexstakeanalyzer/Hex-Stake-Analyzer

How the original is used
------------------------
- app.js is the original analyzer and is NOT modified. Its copyright notice is
  kept, and its license line is shown in the site footer
  ("© 2026 HexStakeAnalyzer · GPL-3.0 · Source").
- Everything StakeScreener adds lives in separate files that wrap or extend the
  analyzer at runtime (for example by wrapping renderAll), so a new upstream
  version can be dropped in without merging.
- All published files and their SHA-256 fingerprints:
  https://github.com/stakescreener/stakescreener

Files added by StakeScreener
----------------------------
denarnica.js / denarnica.css   Wallets Screener: balances, token values, summary
                               cards (Total, Stake Value, Wallet Balance,
                               Validators), network status, shareable codes
koda.php                       stores a saved wallet set under a random code
                               (outside the web root, deleted after 180 days)
gp-validatorji.js              Validator Screener (PulseChain validators, Vouch vPLS)
gp-communis.js                 Communis Screener (COM bonuses per HEX stake)
gp-hedron.js                   Hedron Screener (mintable HDRN per HEX stake / HSI)
gp-icosa.js                    Icosa Screener (HDRN and ICSA stakes, WAATSA NFTs)
gp-skupaj.js / gp-skupaj.css   Total HEX card and Total HEX column
gp-trak.js                     scrolling price ticker
gp-vir.js                      FusionScan as primary PulseChain explorer, official
                               explorer as fallback
gp-prenos.js                   one-time import of settings from the previous domain
gp-podpora.js                  one-time "Support the project" note
gp-preobleka.css               StakeScreener look (layout, fonts, colours)
info.html / gp-info.*          Disclaimer, Privacy, Support, Verify this site
fonts/, slike/, og.png, icons  local fonts, images and icons (no CDN)
robots.txt, sitemap.xml, site.webmanifest
