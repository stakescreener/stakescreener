StakeScreener — external addresses and CSP
==========================================

Local resources
---------------
Chart.js, Inter, Raleway and Space Mono are included locally, so the site does
not need cdnjs.cloudflare.com, fonts.googleapis.com or fonts.gstatic.com.

connect-src
-----------

  - ./code.php: saved wallet codes

The active policy is set in .htaccess (Content-Security-Policy header).

Other directives
----------------
default-src 'self'; base-uri 'none'; object-src 'none'; form-action 'none';
frame-ancestors 'self'; script-src 'self'; script-src-attr 'unsafe-inline';
style-src 'self'; style-src-attr 'unsafe-inline'; font-src 'self';
img-src 'self' data:; worker-src 'none'; frame-src 'none'; media-src 'none';
manifest-src 'self'; upgrade-insecure-requests

Notes
-----
- 'unsafe-inline' for attributes is needed because of the original application's
  onclick and style attributes. All scripts and styles are in local files.
- GitHub source links in the footer are plain links, not connect-src calls
  (raw.githubusercontent.com and api.github.com are used only by "Verify this site").
- The site makes no calls for sign-in, analytics, telemetry, WebSockets,
  service workers or external fonts/CDN libraries.
- CSP does not replace CORS permission on each RPC/API server.
