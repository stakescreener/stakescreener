Privacy

In your browser

The wallet addresses, labels, custom tokens, validator numbers and validator count you enter are stored only in your browser (localStorage). “Clear” removes them. No accounts, no tracking cookies, no analytics.

“Save as code”

Only if you press Save as code, the listed addresses, their labels, the validator count and any validator numbers you added are stored on our server under a random code, so you can open the same set on another device. Nothing else is stored with it (no IP address, no e-mail). A code is deleted automatically 180 days after it was last saved. Anyone who knows a code can open that set — treat it like a link you share.

Third-party services

To show balances and prices, your browser contacts public services directly: blockchain explorers and RPC nodes (FusionScan, PulseChain, PublicNode, Liberty Swap RPC and Ethereum RPC providers), CoinGecko, DexScreener, CoinPaprika and the PulseX subgraph. They see your IP address and the addresses you look up, under their own privacy policies. Wallet addresses and transactions are public on the blockchain by nature.

Verify this site

The screener never asks you to connect a wallet or sign anything (only the Safe Manager does, and only when you click “Connect wallet”). The real risk for a site like this is a compromised server: someone could swap the support address, change a link or add a tracking script. So the exact files of this site are published on GitHub with their SHA-256 fingerprints — a record that does not live on our server.

Verify now downloads each file of this site as your browser receives it, computes its SHA-256 fingerprint and compares it with the published record. If all match, the site is exactly the published source, including the support address above.

Source on GitHub

A check that runs on the page can be faked together with the page, so the independent record is GitHub itself: you can compare the fingerprints there (SHA256SUMS.txt) with curl -s https://stakescreener.com/info.html | sha256sum. Server-side files (.htaccess, code.php) are published for transparency but cannot be checked from the browser.
